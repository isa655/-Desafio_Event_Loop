Call Stack: executa funções JavaScript, uma por vez. Web APIs / I/O: timers e operações assíncronas podem avançar sem bloquear a thread principal. Callback Queue: callbacks prontos aguardam sua vez. Event Loop: verifica quando a Call Stack está livre e permite que callbacks elegíveis sejam executados. No Node.js, o loop também coordena fases de callbacks e operações de I/O.

Atenção: esta é uma simulação didática simplificada, não uma reprodução exata do runtime do Node.js.
